# Sprite assets

Add your sprite images here. Supported formats are PNG and WebP with alpha.

Expected filenames:
- `player.png` or `player.webp`
- `asteroid.png` or `asteroid.webp`
- `shot.png` or `shot.webp`
- `explosion.png` (sprite sheet, 4x4 frames at 64x64 each; add your own asset)

Sprites are scaled at runtime to match sizes from `constants.py`.
